# Sales Summary Generator

A simple Python script to extract sales insights from an SQLite database and visualize results.

## 🚀 Features
- Connects to an SQLite database
- Runs SQL queries to calculate total quantity sold and revenue
- Displays results in the terminal
- Visualizes data with bar charts

## 📦 Requirements
- Python 3.x
- Libraries: `pandas`, `matplotlib`, `sqlite3`

Install dependencies:
```bash
pip install pandas matplotlib
